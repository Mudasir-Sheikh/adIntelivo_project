# Google Ads API re-review packet

## One-paragraph use case

AdIntelivo is subscription software for marketing agencies. An authenticated
agency user can connect Google Ads accounts that the agency is already authorized
to access through Google OAuth. AdIntelivo uses the Google Ads API for reporting
and read-only data retrieval so the agency can review first-party account and
campaign performance in its workspace and client reports. The integration does
not create, edit, pause, enable, or remove campaigns, ads, keywords, or budgets.
Competitive intelligence in AdIntelivo is collected separately from public search
observations, public landing pages, and licensed market-data providers; the Google
Ads API is not used to access competitors' private account data.
